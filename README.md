# 🚀 CampusMart

A full-stack MERN application for managing products and user interactions.

---

## ✨ Features
- 🔐 User Authentication (JWT)
- 📦 Product CRUD (Add, Update, Delete)
- 🔍 Search & Filter
- 🛒 Cart System
- 🌐 MongoDB Atlas Integration

---

## ⚙️ Tech Stack
- Frontend: React.js  
- Backend: Node.js, Express.js  
- Database: MongoDB Atlas  

---

## 🚀 Run Locally

### Backend
cd backend  
npm install  
npm run dev  

### Frontend
cd frontend  
npm install  
npm start
